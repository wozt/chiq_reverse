# Public repository scope

This repository contains notes, probes, scripts, public board photos, and offline-analysis metadata for a personally owned CHiQ U43H7L.

Excluded from the public repository:

- raw eMMC/firmware/partition dumps and extracted proprietary root filesystems;
- private signing keys or bundled helper binaries;
- local connector configuration and runtime caches;
- the TV MAC address and full serial number.

The assessment remains non-destructive: no firmware was flashed and no persistent TV state was modified.
